# NexusOS Portfolio

Standalone portfolio from `waley7337/NexusOS` pull request #20 (`24730b609641486582d6d760530715fb02eea9ca`).

The app lives in `nexusos-portfolio/` and compiles the NexusOS frontend modules it imports from `ai-business-os/ai-business-os/frontend/`. Those modules are the original files, unchanged. The rest of NexusOS is not in this repository.

See `nexusos-portfolio/README.md` for build, test, and Vercel instructions. On Vercel, set the root directory to `nexusos-portfolio` and keep files outside that directory included in the build.
